# mehmetcinar.com

Mehmet Cinar's site: Posts on learning electricity from zero, and on development tooling.

Built with [Astro](https://astro.build) on the [AstroPaper](https://github.com/satnaing/astro-paper) theme (MIT).

```bash
bun install
bun run dev     # http://localhost:4321
bun run build   # astro check, build, Pagefind index
```
